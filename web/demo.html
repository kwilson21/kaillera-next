Rollback netplay predicts the opponent's inputs and runs your game locally without waiting. When predictions miss, the engine rewinds and replays. The round-trip is still on the wire — rollback hides it from you. Lockstep waits the full round-trip every frame, so all latency is felt directly. In this demo, P2 is a synthetic peer running in the same tab. During menus it stays inert so you can navigate freely. Once the match starts, P2 plays random inputs at human cadence — every change is a misprediction the engine has to roll back through, which is what fills the Rollbacks counter. Predictions counts every frame the engine ran ahead of P2's input regardless of whether the prediction was correct.
